# 待办：架构收敛（外部 MCP 统一走 DSH）

> 决策（2026-08-24）：采用**三层架构**——外部 MCP / Skill 统一由 DSH 消费（主通道），
> PLW 只保留知识库 MCP Server + 调度 + 桌面壳；PLW 的 MCP Client 总线为**过渡态**，本次不拆。
> 对应应用内待办 id 4/5/6（本文件为仓库内持久记录，防应用数据丢失后无从追溯）。

## 背景

- 架构图与说明见 `doc/architecture.svg` 与 README「🏗️ 架构」节。
- 原状：PLW 既是 MCP Server（19 工具），也带 MCP Client 总线（`common/mcp_client.py`、`/api/mcp/servers`），并主动调 SAP MCP（调度器 `_sync_sap_and_import`）。
- 方向：外部能力（SAP 等 MCP Server、Skill）**直接配置进 DSH**；PLW 不再对外连 MCP。
