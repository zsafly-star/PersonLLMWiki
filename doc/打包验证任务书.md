```bash

start "" "release\dist\PersonLLMWiki\PersonLLMWiki.exe"
# 等待 3-8 秒后：
curl.exe -s -o NUL -w "%{http_code}" http://127.0.0.1:5000/shell          # 预期 200
```

## 5. 边界与约束

1. **不改源码**——仅执行构建/校验/冒烟；发现疑似代码问题只报告，不修改；
2. **不干扰用户环境**——不 kill 用户运行的 :5000 实例；冒烟用临时实例；
3. **GUI 无法点击**——交互式验证（安装向导、窗口操作）超出能力范围，需人工；
4. **安装包真机验证**——Setup.exe 安装后能否运行需人工实测，工具只验证产物存在性。
