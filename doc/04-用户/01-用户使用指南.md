# PersonLLMWiki 用户使用指南

本指南面向 PersonLLMWiki 的普通使用者。PersonLLMWiki 以压缩包（zip）形式分发，您只需在 Windows 10/11 64 位系统上解压即可运行，无需安装 Python 或任何编程工具。

---

## 1. 系统要求

在开始使用前，请确认您的电脑满足以下条件：

- 操作系统：Windows 10 或 Windows 11，64 位版本
- 无需安装 Python、conda 或任何编程工具，所有运行环境已内置在软件包中
- 磁盘空间：至少预留约 500MB 可用空间
- 浏览器：建议使用 Chrome 或 Microsoft Edge 浏览器以获得最佳体验

---

## 2. 安装步骤

PersonLLMWiki 无需单独安装，解压后双击启动即可，首次启动会自动完成环境检查和初始化。

### 步骤 1：解压软件包

将下载得到的 `PersonLLMWiki-v1.0.0.zip` 压缩包解压到任意目录。

- 推荐解压位置示例：`D:\PersonLLMWiki`
- 也可以解压到桌面或其他您方便找到的位置
- 解压后会得到一个包含所有程序文件的文件夹

### 步骤 2：双击启动

双击解压目录中的 `启动.bat` 文件。

首次启动时会自动完成以下操作：

- 检查 Python 运行时和依赖是否完整（缺失会自动安装）
- 创建用于保存数据的数据目录
- 创建桌面快捷方式
- 自动启动服务并打开浏览器

### 步骤 3：开始使用

启动后，浏览器会自动打开并显示软件主界面。

- 默认访问地址：http://127.0.0.1:5000
- 如果浏览器没有自动弹出，请手动在浏览器地址栏输入上述地址

---

## 3. 日常使用

### 3.1 启动

日常启动软件有以下两种方式：

- 方式一：双击桌面上的「PersonLLMWiki」图标
- 方式二：双击安装目录中的 `启动.bat` 文件

启动后浏览器会自动打开软件主界面。

如果软件已经在运行（端口已被占用），再次启动时会自动打开已运行的实例，不会重复启动。

### 3.2 停止

停止软件有以下两种方法：

- 方法一：直接关闭运行软件时弹出的黑色命令行窗口
- 方法二：双击安装目录中的 `停止.bat` 文件

### 3.3 功能模块

PersonLLMWiki 包含以下功能模块：

| 模块 | 功能 |
|------|------|
| 工作台 | 首页仪表盘，显示天气、最近文章、任务等 |
| 对话 | AI 智能对话，支持多模型、知识库检索、MCP 工具 |
| 文章 | Markdown 文章管理 |
| 任务 | 待办事项管理 |
| Wiki | 知识库编译与检索 |
| 图片 | 图片库管理 |
| 控制台 | 定时 AI Agent 自动化任务 |
| 设置 | 模型配置、主题、头像等个性化设置 |

## 4. 升级

当有新版本发布时，您可以按照以下步骤完成升级：

1. 双击安装目录中的 `升级.bat` 文件
2. 升级程序会自动执行以下操作：
   - 检查当前版本与最新版本
   - 下载更新文件
   - 应用更新到程序目录
3. 整个升级过程约 30 秒即可完成
4. 升级过程中您的数据不会丢失
5. 升级完成后，双击桌面上的「PersonLLMWiki」图标重新启动即可使用新版本

## 5. 配置说明

### 5.1 AI 模型配置

要使用 AI 对话功能，需要先配置 AI 模型：

1. 进入软件主界面，点击「设置」模块
2. 选择「模型接入」选项
3. 填写以下信息：
   - API Key：从模型服务提供商处获取的密钥
   - Base URL：模型服务的访问地址
4. 支持配置多个模型，可在对话中切换使用

### 5.2 .env 文件（可选）

安装目录下存在一个 `.env` 文件，用于存放高级配置项。

- 大部分用户不需要修改此文件，软件已采用合理的默认配置
- 高级用户可根据需要编辑安装目录下的 `.env` 文件
- 修改 `.env` 文件后，需要先停止服务再重新启动，配置才会生效

## 6. 常见问题（FAQ）

**Q：启动后浏览器没有自动打开怎么办？**
A：请在浏览器地址栏手动访问 http://127.0.0.1:5000 即可打开软件主界面。

**Q：端口 5000 被占用怎么办？**
A：编辑安装目录下的 `.env` 文件，将端口设置为其他值，例如 `PORT=5001`，然后重启服务，并使用新端口访问。

**Q：如何备份数据？**
A：将安装目录下的 `resource` 文件夹完整复制到其他位置即可完成备份。

**Q：升级后数据会丢失吗？**
A：不会。升级过程只更新程序文件，`resource` 数据目录不参与升级，您的所有数据都会完整保留。

**Q：杀毒软件报警怎么办？**
A：这是杀毒软件对 Python 脚本的误报，请将软件目录添加到杀毒软件的信任列表中即可正常运行。

**Q：如何完全卸载？**
A：按以下步骤操作即可完全卸载：
1. 先停止正在运行的服务
2. 删除整个软件安装目录
3. 删除桌面上的「PersonLLMWiki」快捷方式

**Q：换电脑怎么迁移？**
A：将整个软件目录完整复制到新电脑上，然后双击 `首次安装.bat` 重新创建快捷方式即可，原有数据会一并迁移。

**Q：能在局域网内共享使用吗？**
A：可以。编辑安装目录下的 `.env` 文件，设置 `FLASK_HOST=0.0.0.0`，然后重启服务。局域网内其他电脑可通过浏览器访问 `http://您的电脑IP:5000` 来使用。

## 7. 数据存储位置

PersonLLMWiki 的所有数据都保存在安装目录下的 `resource` 文件夹中，具体结构如下：

- `resource/instance/sseditor.db` — 所有核心数据（文章、任务、设置等）均存储在此数据库文件中
- `resource/article/` — 文章文件存放目录
- `resource/wiki/` — Wiki 页面存放目录
- `resource/img/` — 图片文件存放目录
- `resource/attachments/` — 附件文件存放目录

备份或迁移时，只需保留整个 `resource` 文件夹即可。

## 8. 技术支持

如果您在使用过程中遇到问题，可以按以下方式获取支持：

1. **查看日志**：先打开安装目录下的 `logs` 文件夹，查看其中的日志文件，日志中可能包含问题的详细原因。
2. **联系提供者**：如果自行排查无法解决，请联系软件提供者，并提供相关的日志信息，以便更快定位问题。
