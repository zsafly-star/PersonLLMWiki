# PersonLLMWiki 分发部署方案

> 目标用户：**非技术人员**（不会命令行、不装 Python、不开终端）
> 首要平台：**Windows 10/11 x64**（后续可扩展 macOS/Linux）
> 核心原则：**解压即用、双击启动、一键升级**

---

## 1. 现状分析

### 1.1 当前痛点

| 环节 | 现状 | 问题 |
|------|------|------|
| 安装 | 手动装 conda → 建环境 → git clone → pip install | 非技术人员无法完成；conda 非必需 |
| 启动 | `dev.ps1` 硬编码 `%USERPROFILE%\miniconda3\envs\flask\python.exe` | 换台机器路径就错；依赖 conda 在 PATH |
| 升级 | `self_update.py` 启动时 `git pull` + `pip install` | 依赖 git 在 PATH；pip 可能不在 PATH |

### 1.2 依赖分析

```
requirements.txt
├── flask, flask-sqlalchemy, flask-cors    ← 纯 Python，无问题
├── openai, requests, markdown, jieba       ← 纯 Python
├── rank_bm25, APScheduler, python-dotenv   ← 纯 Python
├── greenlet==3.1.1                         ← 有 C 扩展，但有 wheel
├── pymupdf                                 ← 有 C 扩展，有 wheel（~30MB）
├── fastembed                               ← 依赖 onnxruntime，有 wheel（~50MB）
└── fastmcp                                 ← 纯 Python
```

所有依赖在 Windows x64 上均有预编译 wheel，**无需 C 编译器**，适合 Embedded Python。

### 1.3 数据目录分析

```
resource/                          ← Config.RESOURCE_BASE_PATH（可通过环境变量配置）
├── instance/
│   └── sseditor.db               ← SQLite 数据库（用户所有数据）
├── article/                      ← 文章 Markdown 文件
├── img/                          ← 上传图片
├── attachments/                  ← 附件 + 对话导出
└── wiki/                         ← Wiki 页面 Markdown
```

**关键约束**：升级时 `resource/` 必须保留，其余代码可覆盖。

## 2. 方案选型

| 方案 | 原理 | 优点 | 缺点 | 结论 |
|------|------|------|------|------|
| **A. Embedded Python** | 微软官方 Python embeddable zip 随包分发 | 体积可控（~100MB）；官方维护；无需管理员权限 | 首次需引导 pip | **✅ 选定** |
| B. PyInstaller | 编译成单个 exe | 单文件分发 | 编译复杂；体积 200MB+；MCP 二进制难打包 | ❌ |
| C. Docker | 容器化 | 环境隔离 | 普通用户装 Docker 更难 | ❌ |

**选型理由**：Embedded Python 是官方提供的免安装版本，体积小、兼容性好，配合引导脚本可实现"解压即用"。

### 3.1 关键设计决策

| 决策 | 说明 |
|------|------|
| `runtime/` 与 `app/` 分离 | 升级时只覆盖 `app/`，避免重装 Python 依赖 |
| `resource/` 独立于 `app/` | 升级不影响用户数据 |
| `.env` 配置 `RESOURCE_BASE_PATH` | 指向 `../resource`，不随代码路径变化 |
| `VERSION` 文件 | 升级时对比版本号，决定是否需要更新 |
| **启动即安装** | `启动.bat` 内置环境自检，首次运行自动完成初始化，无需单独的 `首次安装.bat` |

## 4. 安装流程设计

### 4.1 分发包打包流程（开发者侧）

```
开发者执行 packaging/build_release.py
    │
    ├─ 1. 下载 Python 3.12 embeddable zip（如未缓存）
    ├─ 2. 解压到 runtime/，启用 site-packages
    ├─ 3. 引导 pip（get-pip.py）
    ├─ 4. pip install -r requirements.txt 到 runtime/Lib/site-packages/
    ├─ 5. 复制 app/ 代码（排除 resource/, .git/, __pycache__/）
    ├─ 6. 复制 bin/ MCP 二进制
    ├─ 7. 复制启动.bat / 升级.bat / 首次安装.bat
    ├─ 8. 写入 VERSION 文件
    └─ 9. 打包为 PersonLLMWiki-v{版本}.zip
```

### 4.2 Python Embedded 引导细节

Python embeddable zip 默认**不含 pip**，且 `python312._pth` 禁用了 `site`。需要：

**步骤 1：下载并解压**

```python
# packaging/fetch_runtime.py
import urllib.request, zipfile, os

PYTHON_VERSION = "3.12.8"
URL = f"https://www.python.org/ftp/python/{PYTHON_VERSION}/python-{PYTHON_VERSION}-embed-amd64.zip"

def fetch_runtime(target_dir):
    cache = os.path.join(os.environ.get("TEMP", "."), f"python-{PYTHON_VERSION}-embed-amd64.zip")
    if not os.path.isfile(cache):
        print(f"下载 Python {PYTHON_VERSION}...")
        urllib.request.urlretrieve(URL, cache)

    os.makedirs(target_dir, exist_ok=True)
    with zipfile.ZipFile(cache) as z:
        z.extractall(target_dir)
    print(f"Python 已解压到 {target_dir}")
```

**步骤 2：启用 site-packages**

```python
def enable_site_packages(runtime_dir):
    """取消 python312._pth 中 import site 的注释"""
    pth_file = None
    for f in os.listdir(runtime_dir):
        if f.endswith("._pth"):
            pth_file = os.path.join(runtime_dir, f)
            break
    if not pth_file:
        return

    with open(pth_file, 'r') as f:
        lines = f.readlines()

    with open(pth_file, 'w') as f:
        for line in lines:
            if line.strip() == "#import site":
                f.write("import site\n")    # 取消注释
            else:
                f.write(line)
```

**步骤 3：引导 pip**

```python
def bootstrap_pip(runtime_dir):
    """用 get-pip.py 安装 pip"""
    python_exe = os.path.join(runtime_dir, "python.exe")
    get_pip_url = "https://bootstrap.pypa.io/get-pip.py"
    get_pip_path = os.path.join(runtime_dir, "get-pip.py")

    urllib.request.urlretrieve(get_pip_url, get_pip_path)
    subprocess.run([python_exe, get_pip_path, "--no-warn-script-location"], check=True)
    os.remove(get_pip_path)
```

**步骤 4：安装项目依赖**

```python
def install_requirements(runtime_dir, requirements_path):
    python_exe = os.path.join(runtime_dir, "python.exe")
    subprocess.run([
        python_exe, "-m", "pip", "install",
        "-r", requirements_path,
        "--no-warn-script-location"
    ], check=True)
```

## 5. 启动流程设计

### 5.1 启动.bat

```bat
@echo off
chcp 65001 >nul
title PersonLLMWiki
cd /d "%~dp0"

REM 设置环境变量
set RESOURCE_BASE_PATH=%CD%\resource
set PYTHONPATH=%CD%\app

REM 检测端口 5000 是否已占用
netstat -ano | findstr ":5000 " | findstr "LISTENING" >nul
if %errorlevel% equ 0 (
    echo PersonLLMWiki 已在运行，正在打开浏览器...
    start http://127.0.0.1:5000
    exit /b 0
)

echo ═══════════════════════════════════════
echo   PersonLLMWiki 启动中...
echo   浏览器将自动打开 http://127.0.0.1:5000
echo   关闭此窗口即可停止服务
echo ═══════════════════════════════════════
echo.

REM 3 秒后自动打开浏览器
start /b cmd /c "timeout /t 3 /nobreak >nul && start http://127.0.0.1:5000"

REM 启动 Flask
cd /d "%~dp0\app"
"%~dp0\runtime\python.exe" app.py
```

### 5.2 设计要点

| 要点 | 说明 |
|------|------|
| `%~dp0` | 获取 bat 所在目录，确保任意位置都能运行 |
| `RESOURCE_BASE_PATH` | 通过环境变量指定数据目录，替代 config.py 默认值 |
| `PYTHONPATH` | 指向 app/ 目录，让 embedded Python 找到模块 |
| 端口检测 | 避免重复启动，已运行时直接打开浏览器 |
| 延迟打开浏览器 | 等 Flask 启动完成（约 2-3 秒） |
| 关窗即停 | bat 窗口关闭 = 子进程 python.exe 终止 |

### 5.3 停止.bat

```bat
@echo off
chcp 65001 >nul
title 停止 PersonLLMWiki

echo 正在查找并停止 PersonLLMWiki...
for /f "tokens=5" %%a in ('netstat -ano ^| findstr ":5000 " ^| findstr "LISTENING"') do (
    echo 停止进程 PID: %%a
    taskkill /PID %%a /F >nul 2>&1
)
echo 已停止。
timeout /t 2 /nobreak >nul
```

## 6. 升级流程设计

### 6.1 升级策略选型

| 方案 | 依赖 | 优点 | 缺点 |
|------|------|------|------|
| **A. 下载 zip 覆盖**（选定） | 仅 HTTP | 不依赖 git | 需搭建版本清单服务 |
| B. git pull | 需 git | 现有 self_update.py 已实现 | 非技术人员没装 git |

**选型理由**：非技术人员机器上没有 git，方案 A 更可靠。

### 6.2 版本清单机制

在远程服务器（GitHub Releases / 内部 OSS）维护版本清单：

```json
// https://example.com/personllmwiki/versions.json
{
    "latest": "1.2.0",
    "versions": {
        "1.2.0": {
            "url": "https://example.com/personllmwiki/PersonLLMWiki-1.2.0-update.zip",
            "date": "2026-08-06",
            "notes": "新增 Agent 系统；修复对话页历史加载",
            "min_runtime": "1.0.0",
            "size_mb": 15
        },
        "1.1.0": {
            "url": "https://example.com/personllmwiki/PersonLLMWiki-1.1.0-update.zip",
            "date": "2026-07-20",
            "notes": "Wiki 混合检索优化",
            "min_runtime": "1.0.0",
            "size_mb": 12
        }
    }
}
```

**增量包 vs 全量包**：

| 类型 | 内容 | 体积 | 适用 |
|------|------|------|------|
| 全量包 | app/ + runtime/ 完整 | ~250MB | 首次安装、大版本升级 |
| **增量包**（选定） | 仅 app/ 代码 | ~15MB | 日常小版本升级 |

### 6.3 升级.bat

```bat
@echo off
chcp 65001 >nul
title PersonLLMWiki 升级
cd /d "%~dp0"

echo ═══════════════════════════════════════
echo   PersonLLMWiki 升级
echo ═══════════════════════════════════════
echo.

REM Step 1: 停止正在运行的服务
echo [1/5] 停止服务...
for /f "tokens=5" %%a in ('netstat -ano ^| findstr ":5000 " ^| findstr "LISTENING"') do (
    taskkill /PID %%a /F >nul 2>&1
)
timeout /t 1 /nobreak >nul

REM Step 2: 检查版本
echo [2/5] 检查最新版本...
runtime\python.exe "%~dp0\app\common\upgrade_check.py" check
if errorlevel 2 (
    echo.
    echo 已是最新版本，无需升级。
    pause
    exit /b 0
)
if errorlevel 1 (
    echo.
    echo 检查版本失败，请检查网络连接。
    pause
    exit /b 1
)

REM Step 3: 下载增量包
echo [3/5] 下载更新包...
runtime\python.exe "%~dp0\app\common\upgrade_check.py" download
if errorlevel 1 (

    pause
    exit /b 1
)

REM Step 4: 备份 + 应用更新
echo [4/5] 应用更新...
runtime\python.exe "%~dp0\app\common\upgrade_check.py" apply
if errorlevel 1 (
    echo 更新失败，已自动回滚。
    pause
    exit /b 1
)

REM Step 5: 更新依赖（如有变化）
echo [5/5] 检查依赖更新...
runtime\python.exe -m pip install -r app\requirements.txt --quiet 2>nul

echo.
echo ═══════════════════════════════════════
echo   升级完成！双击"启动.bat"开始使用
echo ═══════════════════════════════════════
pause
```

### 6.4 upgrade_check.py（核心升级逻辑）

```python
"""升级检查与执行模块。
子命令：
  check    - 检查是否有新版本，exit code: 0=有更新, 2=已最新, 1=错误
  download - 下载增量包到临时目录
  apply    - 备份当前 app/，解压新代码，保留 resource/
"""

import os
import sys
import json
import shutil
import tempfile
import urllib.request
import zipfile

VERSIONS_URL = "https://example.com/personllmwiki/versions.json"
PROJECT_ROOT = os.path.dirname(os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
APP_DIR = os.path.join(PROJECT_ROOT, "app")
VERSION_FILE = os.path.join(PROJECT_ROOT, "VERSION")
DOWNLOAD_DIR = os.path.join(tempfile.gettempdir(), "personllmwiki_update")

PRESERVE_PATTERNS = [
    "resource/",
    "runtime/",
    ".env",
    "VERSION",
    "启动.bat",
    "升级.bat",
    "首次安装.bat",
    "停止.bat",
]


def get_current_version():
    if os.path.isfile(VERSION_FILE):
        with open(VERSION_FILE) as f:
            return f.read().strip()
    return "0.0.0"


def fetch_versions():
    """获取远程版本清单"""
    try:
        with urllib.request.urlopen(VERSIONS_URL, timeout=10) as resp:
            return json.loads(resp.read())
    except Exception as e:
        print(f"获取版本信息失败: {e}")
        return None


def cmd_check():
    """检查是否有新版本"""
    current = get_current_version()
    print(f"当前版本: {current}")

    data = fetch_versions()
    if not data:
        sys.exit(1)

    latest = data.get("latest", "0.0.0")
    print(f"最新版本: {latest}")

    if _version_compare(latest, current) <= 0:
        sys.exit(2)

    info = data["versions"][latest]
    print(f"更新内容: {info.get('notes', '')}")
    # 保存下载信息供 download 命令使用
    os.makedirs(DOWNLOAD_DIR, exist_ok=True)
    with open(os.path.join(DOWNLOAD_DIR, "update_info.json"), "w") as f:
        json.dump({"version": latest, **info}, f)
    sys.exit(0)


def cmd_download():
    """下载增量包"""
    info_path = os.path.join(DOWNLOAD_DIR, "update_info.json")
    if not os.path.isfile(info_path):
        print("未找到版本信息，请先执行 check")
        sys.exit(1)

    with open(info_path) as f:
        info = json.load(f)

    url = info["url"]
    zip_path = os.path.join(DOWNLOAD_DIR, f"update-{info['version']}.zip")

    print(f"下载 {info['size_mb']}MB ...")
    urllib.request.urlretrieve(url, zip_path)
    print(f"下载完成: {zip_path}")
    sys.exit(0)


def cmd_apply():
    """应用更新：备份 → 解压 → 清理"""
    info_path = os.path.join(DOWNLOAD_DIR, "update_info.json")
    with open(info_path) as f:
        info = json.load(f)

    zip_path = os.path.join(DOWNLOAD_DIR, f"update-{info['version']}.zip")
    if not os.path.isfile(zip_path):
        print("更新包不存在")
        sys.exit(1)

    # Step 1: 备份当前 app/
    backup_dir = os.path.join(PROJECT_ROOT, "app_backup")
    if os.path.isdir(APP_DIR):
        if os.path.isdir(backup_dir):
            shutil.rmtree(backup_dir)
        shutil.copytree(APP_DIR, backup_dir)
        print(f"已备份到 {backup_dir}")

    # Step 2: 清空 app/ 并解压新代码
    try:
        if os.path.isdir(APP_DIR):
            shutil.rmtree(APP_DIR)
        with zipfile.ZipFile(zip_path) as z:
            z.extractall(PROJECT_ROOT)
        print("代码已更新")

        # Step 3: 更新 VERSION
        with open(VERSION_FILE, "w") as f:
            f.write(info["version"])

        # Step 4: 清理
        shutil.rmtree(backup_dir)
        os.remove(zip_path)
        print(f"升级到 {info['version']} 完成")

    except Exception as e:
        # 回滚
        print(f"更新失败: {e}，正在回滚...")
        if os.path.isdir(APP_DIR):
            shutil.rmtree(APP_DIR)
        if os.path.isdir(backup_dir):
            shutil.move(backup_dir, APP_DIR)
        print("已回滚到旧版本")
        sys.exit(1)


def _version_compare(a, b):
    """比较版本号，返回 1(a>b) / 0(a==b) / -1(a<b)"""
    pa = [int(x) for x in a.split(".")]
    pb = [int(x) for x in b.split(".")]
    for i in range(max(len(pa), len(pb))):
        va = pa[i] if i < len(pa) else 0
        vb = pb[i] if i < len(pb) else 0
        if va > vb: return 1
        if va < vb: return -1
    return 0


if __name__ == "__main__":
    cmd = sys.argv[1] if len(sys.argv) > 1 else "check"
    if cmd == "check":
        cmd_check()
    elif cmd == "download":
        cmd_download()
    elif cmd == "apply":
        cmd_apply()
    else:
        print(f"未知命令: {cmd}")
        sys.exit(1)
```

### 6.5 升级安全机制

```
升级前                          升级中                           升级后
  │                              │                               │
  ├─ 停止服务                    ├─ 备份 app/ → app_backup/       ├─ 更新 VERSION
  ├─ 检查版本                    ├─ 清空 app/                    ├─ 删除 app_backup/
  ├─ 下载增量包                  ├─ 解压新代码到 app/             ├─ 删除临时 zip
  │                              ├─ 如果失败 → 回滚 backup ──────┤
  │                              │                               │
  │                              └─ resource/ 和 runtime/ 不动   └─ pip install（如依赖变化）
```

| 保障 | 说明 |
|------|------|
| **备份回滚** | 升级失败自动恢复 `app_backup/` |
| **数据安全** | `resource/` 目录不参与升级，永不丢失 |
| **种子同步** | 升级后重启时，`seed/skills/` 和 `seed/mcp/` 自动同步到运行时目录。新增 → 追加、变更 → 覆盖、用户自建 → 保留 |
| **依赖检测** | 升级后检测 `requirements.txt` 的 hash，有变化才 pip install |
| **版本锁定** | `VERSION` 文件记录当前版本，避免重复升级 |

## 9. 打包脚本（开发者侧）

### 9.1 build_release.py

```python
"""构建发布包。
用法：
  python build_release.py 1.2.0           # 全量包（含 runtime）
  python build_release.py 1.2.0 --update   # 增量包（仅 app 代码）
"""

import os
import sys
import shutil
import zipfile

from fetch_runtime import fetch_runtime, enable_site_packages, bootstrap_pip, install_requirements

PROJECT_ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
BUILD_DIR = os.path.join(PROJECT_ROOT, "build")
DIST_DIR = os.path.join(PROJECT_ROOT, "dist")

EXCLUDE_DIRS = {".git", "__pycache__", ".vscode", "node_modules", "resource", "build", "dist"}
EXCLUDE_FILES = {".gitignore", ".flaskenv", "dev.ps1"}


def build_full(version):
    """构建全量包（含 Python 运行时）"""
    target = os.path.join(BUILD_DIR, f"PersonLLMWiki-{version}")
    if os.path.isdir(target):
        shutil.rmtree(target)
    os.makedirs(target)

    # 1. Python 运行时
    runtime_dir = os.path.join(target, "runtime")
    fetch_runtime(runtime_dir)
    enable_site_packages(runtime_dir)
    bootstrap_pip(runtime_dir)
    install_requirements(runtime_dir, os.path.join(PROJECT_ROOT, "requirements.txt"))

    # 2. 应用代码
    copy_app_code(PROJECT_ROOT, target)

    # 3. bat 脚本
    copy_bat_scripts(target)

    # 4. VERSION
    with open(os.path.join(target, "VERSION"), "w") as f:
        f.write(version)

    # 5. 打包 zip
    zip_path = os.path.join(DIST_DIR, f"PersonLLMWiki-{version}.zip")
    shutil.make_archive(zip_path.replace(".zip", ""), "zip", BUILD_DIR, f"PersonLLMWiki-{version}")
    print(f"全量包已生成: {zip_path}")


def build_update(version):
    """构建增量包（仅 app 代码，不含 runtime/resource）"""
    target = os.path.join(BUILD_DIR, f"PersonLLMWiki-{version}-update")
    if os.path.isdir(target):
        shutil.rmtree(target)
    os.makedirs(target)

    copy_app_code(PROJECT_ROOT, target)

    with open(os.path.join(target, "VERSION"), "w") as f:
        f.write(version)

    zip_path = os.path.join(DIST_DIR, f"PersonLLMWiki-{version}-update.zip")
    shutil.make_archive(zip_path.replace(".zip", ""), "zip", target, ".")
    shutil.rmtree(target)
    print(f"增量包已生成: {zip_path}")


def copy_app_code(src_root, target_root):
    """复制 app/ 代码目录"""
    src_app = os.path.join(src_root, "src") if os.path.isdir(os.path.join(src_root, "src")) else src_root
    dst_app = os.path.join(target_root, "app")
    shutil.copytree(src_app, dst_app, ignore=shutil.ignore_patterns(*EXCLUDE_DIRS))


def copy_bat_scripts(target_root):
    """复制 bat 启动脚本"""
    scripts_dir = os.path.join(os.path.dirname(__file__), "scripts")
    for f in os.listdir(scripts_dir):
        if f.endswith(".bat"):
            shutil.copy(os.path.join(scripts_dir, f), target_root)


if __name__ == "__main__":
    version = sys.argv[1]
    is_update = "--update" in sys.argv
    os.makedirs(DIST_DIR, exist_ok=True)
    if is_update:
        build_update(version)
    else:
        build_full(version)
```

## 10. 错误处理与日志

### 10.1 启动日志

在 `启动.bat` 中重定向 stdout 到日志文件：

```bat
REM 启动.bat 中 Flask 启动行改为
"%~dp0\runtime\python.exe" app.py 2>&1 | tee "%~dp0\logs\startup.log"
```

Windows 不自带 `tee`，改用 PowerShell：

```bat
"%~dp0\runtime\python.exe" app.py > "%~dp0\logs\startup.log" 2>&1
```

或直接在 Python 侧配置日志：

```python
# app.py
import logging
logging.basicConfig(
    filename=os.path.join(os.path.dirname(__file__), '..', 'logs', 'app.log'),
    level=logging.INFO,
    format='%(asctime)s [%(levelname)s] %(name)s: %(message)s'
)
```

### 10.2 常见错误处理

| 错误场景 | 表现 | 处理 |
|----------|------|------|
| 端口 5000 被占用 | Flask 启动报 `Address already in use` | 启动.bat 已预检端口 |
| runtime 损坏 | `python.exe` 无法执行 | 首次安装.bat 重新引导 |
| 数据库锁定 | `database is locked` | 确保只有一个实例运行 |
| 依赖缺失 | `ModuleNotFoundError` | 升级.bat 自动 pip install |
| 防火墙拦截 | 浏览器打不开 | 监听 `127.0.0.1` 不触发防火墙（仅本机访问） |

## 10.5 Web 端在线更新（设置页 → 关于页签）

除了 `升级.bat` 命令行方式外，用户也可以直接在 Web 页面完成更新：

```
设置 → 关于页签
  ├─ 显示当前版本号、Python 版本、运行模式
  ├─ 点击"检查更新"
  │    └─ POST /api/settings/upgrade/check
  │         └─ 后端读取 VERSION，对比远程 versions.json
  │              ├─ 已最新 → 提示"已是最新版本"
  │              └─ 有新版 → 显示新版本号 + 更新日志 + "立即更新"按钮
  └─ 点击"立即更新"
       └─ POST /api/settings/upgrade/apply
            ├─ 后端调用 common/upgrade_check.py 下载 + 备份 + 解压
            ├─ 返回成功 → 提示"更新完成，请重启服务"
            └─ 返回失败 → 提示错误信息（已自动回滚）
```

**API 设计**：

| 接口 | 方法 | 返回 |
|------|------|------|
| `/api/settings/version` | GET | `{current, python_version, mode, git_repo}` |
| `/api/settings/upgrade/check` | POST | `{has_update, latest, notes, size_mb}` |
| `/api/settings/upgrade/apply` | POST | `{success, new_version, message}` |

**安全约束**：
- 开发模式（存在 `.git` 目录）下禁用在线更新，返回提示"请使用 git pull 更新"
- 更新前自动停止正在运行的子进程（MCP 服务等）
- 备份 + 回滚机制（`app_backup/`）
