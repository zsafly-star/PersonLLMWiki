# 工作台（首页）设计方案

## 设计理念

首页是一份**每日简报**，像早晨喝咖啡时扫一眼的报纸头版。信息精选、留白充裕、节奏缓慢。

核心体验：3 秒扫完今天要做什么，10 秒看完发生了什么，然后安心开始工作。

## 各区域说明

### 问候区

大字号、居中偏左，营造"这是你的空间"的亲近感。

- 根据时段：「早安」「上午好」「下午好」「晚上好」+ 用户名
- 日期：年 / 月 / 日 + 星期，大号显示
- 天气：右上角一角，温度 + 城市，不抢视线

天气组件保持轻量三层结构：默认显示温度+城市，悬停展开细节（湿度/风力/AQI/3天预报），点击城市切换城市。API 失败时静默降级为"--"，不阻塞页面。

### 今天要做什么

页面核心，第一屏最重要区域。只展示活跃任务（最多 6 条），按截止时间排序。

- 每条可勾选，勾选即完成，带轻微过渡动画
- 标注截止日：今天到期（红色）、明天到期（橙色）、本周内、无截止
- 空状态：「今天没有待办任务，享受清闲。」
- 溢出链接：「还有 N 项 · 看板查看全部」

### 值得关注

轻量提醒区，只在有事时才凸显。全部正常时不显示这一节。

- 待审批数量 → 点击进入审批页
- 公共库同步摘要 → 点击浏览新增概念
- 编译异常 → 点击查看详情

空状态：整节不渲染。用户打开页面如果没有关注事项，就不会看到这一块。

### 最近更新

知识库的动态摘要，最多 5 条，帮助感知"知识在流动"。

- 标题 + 相对时间（几分钟前 / 几小时前 / 昨天）
- 区分来源：公共库概念标注"公共"
- 点击直接打开对应页面

空状态：「知识库还没有内容，去 AI 对话中开始积累吧。」

### Command Bar

页面底部常驻输入框，居中，不抢上方内容节奏。

- 聚焦时显示最近搜索/最近浏览
- 回车 → 跳转 AI 对话页并自动发起新会话
- 支持直接输入搜索关键词模糊匹配知识页面

### 系统脉搏

页面最底部一行极简状态，字号更小：

```
● 公共库已同步  ● MCP 5/5  ● 调度器运行中
```

仅在一行内展示，且只在有异常时引人注意（如某服务断开时变灰）。

## 信息取舍

日报风格的核心是**精选，而非全量**。以下内容不放在首页：

| 不放首页 | 原因 |
|----------|------|
| 知识页面总数、概念词条数等总量统计 | 静态数字，每天不变，无行动价值 |
| 流程进度（待办/进行中/已完成计数） | 信息与"今日任务"重叠 |
| 独立系统状态卡片 | 信息密度太低，一行足矣 |
| 快捷标签/快捷入口链接列表 | 侧边栏已有导航，Command Bar 已覆盖核心操作 |

## 天气组件

Header 右上角，轻量辅助信息，帮助当日出门决策。

三层结构：
- 默认态：温度 + 城市 + 天气图标（不展开）
- 悬停展开：湿度、风力、AQI、紫外线、3 天预报
- 点击"详情"跳转完整天气页

决策建议（服务端按优先级生成，命中即停）：

| 优先级 | 条件 | 建议 |
|:--:|------|------|
| 1 | 有预警 | ⚠️ {类型}{等级}预警，请留意安全 |
| 2 | 降水概率 ≥ 60% | 今天有雨，出门记得带伞 |
| 3 | 温差 ≥ 10℃ | 早晚温差大，建议带件外套 |
| 4 | AQI > 150 | 空气污染较重，外出建议戴口罩 |
| 5 | 最高温 ≥ 35℃ | 高温天气，注意防暑补水 |

交互：异步加载不阻塞 / 30~60 分钟刷新 / 失败静默降级 / 后端代理不暴露第三方 Key。

## 设计原则

1. **精选胜于全量** — 用户不需要看到一切，只需要看到该看的
2. **留白即呼吸** — 大间距、大字号、少卡片，让眼睛有休息空间
3. **有事说事，没事安静** — 关注区无内容时不展示，不给虚假的"暂无"提醒
4. **增量而非总量** — "新增了 3 个概念"比"共有 128 个概念"有用
5. **可操作直接操作** — 任务勾选、点击跳转都在当前页面完成
6. **降级优雅** — 天气失败、API 超时、空数据，都不影响页面正常渲染
