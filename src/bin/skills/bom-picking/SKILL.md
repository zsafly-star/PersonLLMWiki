# PCB BOM 检查与领料

## 概述

对 PCB 原始 BOM（Excel .xlsx）执行标准化检查，查询 SAP 库存，最终生成领料单。

**完整流程分三大步：**

**第一步：BOM 数据检查（四项检查按顺序执行）**
1. 列结构检查（必须 4 列 + 可选"层"列）
2. 空白内容检查（有层时按 Top/Bottom 分别处理）
3. 品号重复检查（有层时按 Top/Bottom 分别处理）
4. 物料描述隐式重复检查（单位不同但值相同）

**第二步：SAP 库存查询**
- 如果有层：先合并 Top+Bottom 品号（extract_parts 自动完成），再查询
- 对每个品号查询 SAP 库存，优先仓库 1003/1004/1016
- 无库存的物料走替换流程

**第三步：生成领料单**
- 序号、品号、数量、仓库、批次

## 前置条件

- Python 已安装 `openpyxl` 库（如缺失，先运行 `pip install openpyxl -q`）
- 脚本路径: `scripts/check_bom.py`（与本文件同级的 scripts 子目录）
- SAP MCP 工具可用（`mcp_sap-mcp` 服务）

## 工作流程

### 第 0 步：运行分析脚本

```bash
python <skill目录>/scripts/check_bom.py analyze "<BOM文件路径>"
```

脚本输出 JSON，包含 `column_check`、`blanks`、`duplicates`、`summary` 四个部分。
读取 JSON 后按以下顺序处理。

---

### 检查 1：列结构

**必须列（4 列）：** 品号、物料描述、位号(Designator)、数量(Quantity)
**可选列：** 层(Layer) — 有则按层分组检查，无则整体检查

判断 `column_check.passed` 和 `has_layer`：
- **passed = false** → **立即停止**，向用户报告：
  - 缺失的必须列（`required_missing`）
  - 实际表头列表
  - 提醒用户补齐缺失的必须列后再重新检查
- **passed = true** → 记录 `has_layer` 值，继续检查 2

**关键分支：**
- `has_layer = true` → 检查 2/3/4 中每个条目都带 `layer` 字段（Top/Bottom），需按层分别向用户展示
- `has_layer = false` → 正常整体处理

**列检查未通过时不得继续后续步骤。**

---

### 检查 2：空白内容

判断 `summary.blank_count`：
- **= 0** → 无空白，跳到检查 3
- **> 0** → 按 `blanks` 数组逐条处理

**有层时（`has_layer = true`）：** 先按 `layer` 字段分组（Top / Bottom），分别向用户展示各层的空白。弹窗问题时注明所属层，如 `位号 [designator]（[Top]）的 [列名] 为空`。

#### 交互方式

使用 **AskUserQuestion** 工具，按位号弹窗询问用户。每次最多 4 个问题。

每个空白单元格的问题格式：
- **问题**: `位号 [designator] 的 [列名] 为空，请填写内容`
- **选项**: 根据上下文提供合理建议值，用户也可选 "暂不填写"

**关键规则：**
- 允许用户选择"暂不填写"——跳过该空白，不强制填写
- 如果同一行有多个空白列（如品号和物料描述都空），合并为一个问题
- 用户填写后，用脚本写入：
  ```bash
  python <skill目录>/scripts/check_bom.py fill "<BOM文件路径>" <行号> <标准列名> "<值>"
  ```

**标准列名**（脚本使用的内部名称）：`品号`、`物料描述`、`位号`、`数量`、`层`

处理完所有空白后，继续检查 3。

---

### 检查 3：品号重复

判断 `summary.duplicate_count`：
- **= 0** → 无重复，检查完成
- **> 0** → 按 `duplicates` 数组逐组处理

**有层时（`has_layer = true`）：** 重复按 (品号, 层) 分组——同一品号在 Top 和 Bottom 各出现一次**不算重复**。只有同一层内同品号出现多次才算重复。弹窗时注明所属层。

#### 交互方式

使用 **AskUserQuestion** 工具，对每组重复品号弹窗。每次最多 4 组。

每组重复的问题格式：
- **问题**: `品号 [part_number] 出现 [N] 次：[列出各次出现的位号、层、数量]`
- **选项**:
  - `全部保留` — 保持原样不改动
  - `删除行 [row]（位号 [designator]）` — 每个可删除的行作为一个选项

**关键规则：**
- 用户选择删除时，用脚本执行：
  ```bash
  python <skill目录>/scripts/check_bom.py delete "<BOM文件路径>" <行号1> [<行号2> ...]
  ```
- **批量删除时一次传入所有要删除的行号**（脚本内部从大到小删除，行号不会错乱）
- 如果用户选择"全部保留"，跳过该组

---

### 检查 4：物料描述隐式重复（单位不同）

判断 `summary.implicit_duplicate_count`：
- **= 0** → 无隐式重复，检查完成
- **> 0** → 按 `implicit_duplicates` 数组逐组处理

**背景：** 同一种物料可能因单位写法不同被误当成两种，例如 `100nF` 与 `0.1μF`、`4.7KΩ` 与 `4700Ω`。脚本已把阻值统一到 Ω、容值统一到 pF，分组后找出"标准化描述相同但原始描述不一致"的物料。

#### 交互方式

使用 **AskUserQuestion** 工具，对每组隐式重复弹窗。每次最多 4 组。

每组的问题格式：
- **问题**: `以下物料的值实际相同（标准化后均为 [normalized_description]），但描述写法不同，是否统一？`
- 列出各行的位号/层/原始描述
- **选项**:
  - `统一为 [第一种写法]` — 以该组中最常见的写法为基准
  - `统一为 [第二种写法]` — 若存在多种写法，每种作为一个选项
  - `保持现状不改` — 不修改，跳过该组

**关键规则：**
- 用户选择统一后，对每条需要修改的行调用：
  ```bash
  python <skill目录>/scripts/check_bom.py fill "<BOM文件路径>" <行号> 物料描述 "<统一后的描述>"
  ```
- 只修改"原始描述 ≠ 目标描述"的行，已一致的行不动
- 这种重复通常意味着同一物料被拆成两条，**建议同时提醒用户核查这些行的品号是否也应该合并一致**

---

### 完成报告

四项检查全部完成后，输出汇总：
- 列结构: 通过/未通过
- 空白内容: 原有 X 个，已填写 Y 个，跳过 Z 个
- 品号重复: 原有 X 组，已删除 Y 行，保留 Z 组
- 隐式重复: 原有 X 组，已统一 Y 行，保留 Z 组

如所有检查均通过（无空白、无重复、无隐式重复），提示用户 BOM 检查完成，可进入第二步。

---

## 第二步：SAP 库存查询

### 第 0 步：提取去重品号列表（自动合并 Top/Bottom）

```bash
python <skill目录>/scripts/check_bom.py extract_parts "<BOM文件路径>"
```

输出 JSON 包含 `parts` 数组，每个元素含 `part_number`、`description`、`total_quantity`（聚合后的总需求量）。跳过无品号的行和"虚拟件"。

**合并说明：** 无论 BOM 是否有"层"列，`extract_parts` 始终跨所有行聚合相同品号。即 Top 层和 Bottom 层的同一品号会自动合并为一个条目，需求量累加。无需额外合并步骤。

### 逐个品号查询库存

对 `parts` 中的每个品号，调用 MCP 工具查询库存：

```
run_mcp: mcp_sap-mcp / get_warehouse_info
  args: { "matnr": "<品号>" }
```

返回格式：
```json
{
  "items": [
    {"werks":"1100", "werks_name":"汉威科技工厂", "lgort":"1003", "charg":"266220780", "quantity":"359902.000"},
    ...
  ],
  "total_quantity": "488702.8"
}
```

**跳过规则：** 品号为空或"虚拟件"的行不查询（已在 extract_parts 中过滤）。

### 库存判定与决策

对每个品号，按以下优先级判定：

#### 情况 A：优先仓库（1003/1004/1016）有足够库存

→ 直接使用，记录仓库、批次、可用量。状态 = `ok`

#### 情况 B：优先仓库无库存，但其他仓库有

→ 使用 **AskUserQuestion** 弹窗：
- **问题**: `品号 [pn]（[描述]）需求 [N] 个，优先仓库 1003/1004/1016 无库存，以下其他仓库有库存：[列出仓库+数量+批次]，请选择使用哪个仓库？`
- **选项**:
  - 每个有库存的仓库作为一个选项（显示仓库名 + 库存量 + 批次）
  - `选择替换物料` — 不使用现有库存，走替换流程

#### 情况 C：所有仓库均无库存

→ 自动进入替换流程。

### 替换流程

当用户选择替换（情况 B）或全部无库存（情况 C）时：

1. **查找相似物料**：根据物料描述判断类别（电阻/电容/二极管等），调用：
   ```
   run_mcp: mcp_sap-mcp / query_materials_by_params
     args: { "category": "<类别>", "filters": "<JSON筛选条件>" }
   ```
   从物料描述中提取关键参数（阻值/容值/封装/精度等）作为 filters。

2. **检查候选物料的库存**：对每个候选物料调用 `get_warehouse_info` 查库存。

3. **筛选有库存的候选**：只保留库存 ≥ 需求量的候选物料。

4. **弹窗让用户确认**：使用 **AskUserQuestion**：
   - **问题**: `品号 [原pn] 无库存，找到以下有库存的替代物料，请选择：`
   - **选项**: 每个有库存的替代物料（显示品号 + 描述 + 库存量 + 仓库）
   - 用户可拒绝所有候选，此时标记为 `no_stock`

5. 用户确认后，记录替代品号、仓库、批次。状态 = `replacement`

### 库存查询汇总

所有品号查询完成后，输出汇总：
- **有库存（优先仓库）**: X 个
- **有库存（其他仓库）**: Y 个
- **已替换**: Z 个
- **无库存**: W 个

列出所有 **无库存** 的物料明细（品号、描述、需求量），提醒用户处理。

最后使用 **AskUserQuestion** 弹窗确认：
- **问题**: `是否制作领料单？共有 [N] 个物料（其中 [M] 个无库存将被跳过）`
- **选项**: `制作领料单` / `暂不制作`

用户确认后，进入第三步。

---

## 第三步：生成领料单

### 确认领料数量

对每个有库存或已替换的物料，使用 **AskUserQuestion** 确认领料数量：
- 默认值 = BOM 需求量
- 允许用户修改（如多领备料）
- 无库存（`no_stock`）的物料不列入领料单

**批量确认**：如果物料较多（>10 个），先展示完整列表，然后一次性询问"是否按需求量领料"，用户确认后全部按需求量，否则逐个询问。

### 生成领料单

将确认后的结果写入 JSON 文件（临时文件），然后调用脚本生成领料单：

```bash
python <skill目录>/scripts/check_bom.py gen_picking_list "<json文件路径>"
```

JSON 文件内容格式（数组）：
```json
[
  {
    "part_number": "10001561",
    "description": "贴片电阻-厚膜-1/8W-0Ω-1%-0805-R-OM",
    "required_quantity": 3,
    "selected_warehouse": "1003",
    "selected_batch": "266220780",
    "available_quantity": 359902,
    "status": "ok"
  }
]
```

脚本输出 Markdown 表格：

| 序号 | 品号 | 物料描述 | 需求量 | 仓库 | 批次 | 库存量 | 状态 |
|------|------|----------|--------|------|------|--------|------|

状态列：`正常` / `已替换` / `无库存`

### 完成

将领料单展示给用户，确认完成。

## 常见问题

| 问题 | 处理方式 |
|------|----------|
| openpyxl 未安装 | 运行 `pip install openpyxl -q` |
| BOM 有多个 Sheet | 脚本默认读第一个 Sheet，告知用户 |
| 表头是中英混合（如 Designator/Quantity） | 脚本已内置别名匹配，自动识别 |
| 空白过多（>20 个） | 先汇总告知用户总数，再逐批询问 |
| 物料描述格式不规则 | 隐式重复只对能识别出 Ω/pF 单位的描述生效，其他保持原样 |
| SAP MCP 查询超时或失败 | 重试一次；仍失败则标记该品号"查询失败"，继续处理其余品号 |
| 品号在 SAP 中不存在（get_material 返回 error） | 仍尝试 get_warehouse_info（可能物料主数据未同步但有库存），两者都无则走替换 |
| 替换候选也无库存 | 标记为 `no_stock`，最终汇总中列出 |
| 品号数量多（>50 个） | 库存查询分批进行，每批 10-15 个，中间汇报进度 |
